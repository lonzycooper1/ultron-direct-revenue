Customer journey

Record real inquiries, prepare an agreed proposal and connect an existing paid order to its reviewed printable resource. These steps do not send messages, publish an offer or create a payment.

2. Prepare the agreed proposal

The server uses the existing catalog price. A saved proposal is not evidence that the buyer agreed, received it or paid.

3. Verify an existing payment

The buyer must match the inquiry. The existing purchase code opens private delivery. Email delivery and CRM synchronization remain separate integrations.
